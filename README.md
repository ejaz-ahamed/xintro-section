# XIntro Section

Intro section with dropdown navigation, built for the Crio.Do XIntro Section buildout.

**Live site:** see the Vercel deployment linked in this repo's About section.

## Features

- Features and Company dropdown menus in the header (click to open, click outside or press Escape to close)
- Mobile slide-in navigation drawer with a dimmed overlay and inline dropdowns
- Responsive hero image using `<picture>` (mobile and desktop artwork)
- Hover and focus states for all interactive elements

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and Grid
- Vanilla JavaScript
- Deployed on Vercel
